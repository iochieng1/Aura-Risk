# Languages

AuraRisk speaks English and Swahili (#60). Most people in the Kenyan pilot
areas use Swahili day to day.

> **Before launch:** the Swahili text was written without a native-speaker
> review. Have a native speaker, ideally someone from the pilot area, check
> every string in `packages/shared/src/i18n.ts` and
> `aurarisk-backend/internal/services/i18n.go`. Safety tips and the
> decision-support notice matter most.

## Where the text lives

- **`packages/shared/src/i18n.ts`** is the catalogue the web and mobile apps
  share. `en` defines every key. Every other language is typed
  `Record<MessageKey, string>`, so a missing key fails the build. A jest test
  also checks that no string is empty and that `{placeholders}` match English.
  `translate(lang, key, params)` fills placeholders. `pickLanguage()` maps
  browser or device language tags to a supported language.
- **The backend** writes the risk `summary` and `tips` itself.
  `internal/services/i18n.go` has the Swahili tips (keyed by the English tip)
  and the summary format. They mirror the `tip.*`, `level.*` and
  `risk.summary` entries in the shared catalogue, so change both together. A Go
  test checks that every tip of every level has a translation.

Everything else from the server stays English: confidence reasons, error
messages, push alerts and logs. The apps translate the errors people see
most (network, server and rate-limit errors) themselves.

## Choosing the language

- **API:** `GET /api/risk` and `POST /api/risk` take `lang=en|sw`, or else read
  `Accept-Language` (highest q-value wins, matched on the primary subtag, so
  `sw-KE` counts as Swahili). The default is English. Responses carry
  `Content-Language` and `Vary: Accept-Language`.
- **Web:** a language menu in the header. The choice is remembered in
  `localStorage`; without one, the app uses the first supported language in
  `navigator.languages`. It sets `<html lang>` and sends `lang` with each risk
  request, and reloads the selected place when the language changes.
- **Mobile:** follows the device language (from
  `Intl.DateTimeFormat().resolvedOptions().locale`). The English / Kiswahili
  switch at the top of the main screen overrides it, and the choice is saved
  with AsyncStorage.

Place names, county names and community report notes are shown as written.

## Adding a language

1. Add its code to `Lang`, `LANGUAGES` and `isLang` in
   `packages/shared/src/i18n.ts`, and a full message table to `MESSAGES`. The
   compiler lists any missing keys.
2. In `aurarisk-backend/internal/services/i18n.go`, add the code to
   `supportedLanguage`, plus level names, tips and a summary format, and
   handle it in `LocalizeRisk`.
3. Run the shared jest tests and `go test ./internal/services/`.
4. Have a native speaker review it before release.
